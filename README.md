# Taskboard API

API REST para gerenciamento de tarefas desenvolvida com Java e Spring Boot.

## Tecnologias
- Java 21
- Spring Boot 3.5
- PostgreSQL
- Spring Security
- Spring Data JPA
- Maven

## Configuração

Variáveis de ambiente necessárias:

DB_URL=
DB_USERNAME=
DB_PASSWORD=

## Como executar

./mvnw spring-boot:run
